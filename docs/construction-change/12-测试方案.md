## 一、测试范围与策略

覆盖**正常、边界、对抗、权限、故障**五类场景，共 **32 个可量化测试步骤**，全部基于真实 HTTP 请求执行并逐步留痕（请求 / 响应 / 判定），证据文件 `tests/evidence/results.json`。

| 编号 | 场景 | 步骤数 | 关键校验点 | 结果 |
| --- | --- | --- | --- | --- |
| S1 | 正常场景 | 9 | 全链路闭环：变更登记→交底签收→自动流转→签证核价→业主确认 | 100% 通过 |
| S2 | 边界场景 | 7 | 字段长度上下限、不存在资源、零金额入口校验 | 100% 通过 |
| S3 | 对抗场景 | 6 | SQL 注入、XSS、状态机越权、无 Token、违规意图 | 100% 通过 |
| S4 | 权限场景 | 5 | JWT 无凭证 / 伪造 / 篡改签名，后台越权访问（含对照组） | 100% 通过 |
| S5 | 故障场景 | 5 | 错误密码、错误方法、畸形报文、LLM 未配置降级链路 | 100% 通过 |

## 二、测试环境与工具

- 被测服务：`uvicorn app.main:app @ 127.0.0.1:8010`（独立测试库 test_e2e.db，不污染开发数据）
- 测试驱动：Python httpx（`tools/run_scenarios.py`），全程留痕至 `tests/evidence/results.json`
- 冒烟回归：`pytest tests/test_smoke.py` 8 条全部通过
- 线上环境：WorkBuddy 应用发布沙箱（Python 单端口 HTTP 服务 + SQLite）

## 三、通过标准（量化）

1. **步骤级**：每步断言 HTTP 状态码与业务状态字段，任一步不通过即场景失败；
2. **场景级**：五类场景步骤通过率均须 100%（32/32）；
3. **冒烟级**：pytest 冒烟 8 条全部通过；
4. **安全级**：对抗与权限场景不得出现任何 5xx；降级链路必须给出明确提示而非静默失败。

## 四、关键执行结果（摘录）

- **S1 正常**：变更登记 → 自动建 V1 与 3 条交底任务 → 状态「交底中」→ 3/3 签收 → 自动流转「待签证」→ 签证登记「待核定」→ 核价「待业主确认」→ 确认「已确认」，全链路闭环；
- **S2 边界**：标题 <2 字符与 >200 字符均 422 拒绝；不存在资源统一 404；零金额入口即被 400 拒绝；
- **S3 对抗**：SQL 注入登录 401（参数化查询）；跳过核价直接确认被状态机拦截（422）；无 Token 401；违规意图对话被系统提示词拒绝并审计标红；
- **S4 权限**：伪造 / 篡改 HS256 签名 Token 均 401；管理后台无凭证 401；合法凭证对照组 200；
- **S5 故障**：畸形 JSON 422；错误方法 405；LLM 未配置时 RAG 自动降级 BM25，知识问答不中断，故障后核心功能回归 200。

## 五、缺陷记录与改进项

| 编号 | 发现 | 处理 |
| --- | --- | --- |
| D-01 | 零金额签证入口即被 400 拒绝 | 维持现状，人工核价兜底；如需支持零金额需评审 |
| D-02 | 沙箱无 LLM Key 时 200 降级 / 503 提示两种表现 | 统一为 200 + BM25 降级回答 |
| D-03 | 非法状态流转返回 422（参数层）而非 400（业务层） | 语义可接受，记录口径：状态机拒绝统一 4xx |
