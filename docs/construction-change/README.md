- **业务挖掘** ← 实验室 opportunity 阶段（识别业务机会 / 建立现状基线 / 确认立项与决策链）；
- **行业分析** ← 案例背景（远筑工程 ·"一张变更单的三个版本"）+ 行业共性痛点调研；
- **两张流程图** ← 实验室业务处理流程模型（business graph）与角色访谈问题，分现状与转型后两张；
- **报价单与设计方案** ← 对应 FDE 交付阶段（方案设计 / 构建集成 / 测试评估 / 上线交接）产出要求。
