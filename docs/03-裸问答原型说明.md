# 提示词3 · 裸问答最小原型说明

> 位置：`prototype/rag_prototype.py`（单脚本，不涉及 Web）+ `prototype/data/报销制度示例.md`

## 功能流程

1. **读取本地报销制度 Markdown 文件** → 清理噪音 → 按 500 字滑动窗口切片（相邻片重叠 80 字，防止条款被拦腰截断）
2. **向量化存入 FAISS**：调用 Embedding 接口把每个切片转为向量，归一化后存入 FAISS 内积索引（余弦相似度）
3. **命令行问答循环**：输入问题 → **BM25 + 向量混合检索 Top3**（RRF 排名融合，工业界标准做法）→ 拼入提示词 → 调用 LLM 生成回答 → 输入 q 退出

## 运行方法

```bash
# 1. 安装依赖
pip install faiss-cpu rank_bm25 openai numpy

# 2. 配置 LLM 供应商（三选一，设置环境变量）
set RAG_API_KEY=sk-xxx
set RAG_BASE_URL=https://api.deepseek.com/v1
set RAG_MODEL=deepseek-chat

# 3. 运行
cd prototype
python rag_prototype.py data/报销制度示例.md
```

供应商切换对照表（改环境变量即可，代码零改动）：

| 供应商 | RAG_BASE_URL | RAG_MODEL |
|--------|--------------|-----------|

1. 切片从"定长滑动窗口"改为"按 第X条 条款结构切分"，检索质量更高
