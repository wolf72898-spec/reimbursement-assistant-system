## 快速开始

```cmd
cd /d D:\aworkbuddy\报销助手智能体系统
uvicorn app.main:app --reload
```

浏览器打开 http://127.0.0.1:8000 —— 第一个注册的用户自动成为管理员。
先在「管理员面板 → 知识库」上传 `prototype/data/报销制度示例.md`，再回「智能体对话」提问。
