# 提示词 5 · 管理后台实现说明

> 对应提示词 5：管理后台（登录鉴权 / 知识库管理 / 提示词模板管理 / 对话审计）。
> 已全部实现，入口：以管理员身份登录后，左侧「⚙️ 管理员面板」。

## 一、页面清单（全部在中文网页内，无需 Swagger）

| 页面 | 入口 | 功能 | 权限 |
|------|------|------|------|
| 看板统计 | 管理员面板顶部 | 用户数 / 会话数 / 待提交草稿 / 已提交报销单 | 仅管理员 |
| 📚 知识库 | 管理员面板 · 第一个标签 | 拖拽/点击上传 Markdown/TXT/PDF → 自动切片 → 向量化入库；列表可删除 | 仅管理员 |
| ✏️ 提示词模板 | 管理员面板 · 第二个标签 | 在线编辑 agent/qa/expense 三套模板，保存后立即生效（存数据库，不写死代码）；支持一键恢复默认 | 仅管理员 |
| 🛡️ 对话审计 | 管理员面板 · 第三个标签 | 按员工/时间范围筛选对话记录；疑似违规问答自动标红并注明命中原因 | 仅管理员 |

## 二、接口清单

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/admin/overview` | GET | 看板统计 |
| `/api/knowledge/documents` | POST/GET | 上传（含 PDF）/ 列表（含切片数） |
| `/api/knowledge/documents/{id}` | DELETE | 删除文档及全部切片 |
| `/api/admin/prompts` | GET | 模板列表 |
| `/api/admin/prompts/{name}` | PUT | 保存修改（立即生效） |
| `/api/admin/prompts/{name}/reset` | POST | 恢复内置默认 |
| `/api/admin/audit` | GET | 审计查询（`user_id` / `start` / `end` / `flagged_only` / `page`） |
| `/api/admin/audit/users` | GET | 员工下拉列表 |

所有管理接口服务端校验 `role == "admin"`，非管理员返回 `403 {"detail": "需要管理员权限"}`。

## 三、默认系统提示词（agent 模板，可在后台修改）

> "你是公司报销制度助手，只根据提供的制度条文回答，不确定时明确说'制度中未找到'，回答末尾附引用来源，不得编造报销标准。"

在此基础上按 Agent 化要求扩展为三段式（流程硬规则 / 行为准则 / 错误示范），全文见 `app/agent/prompts/agent.txt`，上传数据库后可在后台编辑。

## 四、违规判定规则（可解释，不做黑盒）

用户消息命中以下关键词即在审计页标红并注明原因：
拆成两张 / 分开发票 / 拆开发票 / 拆单 / 没有发票 / 不要发票 / 找票 / 替票 / 虚开 / 多开点 / 多开一些 / 先斩后奏 等。

同一规则也用于 `validate_expense` 的合规校验（明细含违规表述 → 校验不通过）。

## 五、生效机制（核心设计）

提示词模板存 `prompt_templates` 表；每次对话时从数据库实时读取（`app/agent/loop.py: load_prompt_text`）。管理员保存 → 下一条消息即刻用新模板，无需重启。应用启动时自动播种默认模板（已自定义的不覆盖）。
