# 报销助手智能体系统 — 需求清单与架构方案

> 版本：v0.1 | 日期：2026-10-30 | 状态：待评审确认
> 说明：未决问题按架构师推荐值先行锁定，标注 ⚠️ 的项可随时推翻重议。

## 一、需求范围（一页纸）

| # | 需求项 | 决策（推荐值） | 架构影响 |
|---|--------|--------------|---------|
| 1 | 发票类型 | 首期：电子发票 + 手工填写票据信息；OCR 识别二期 ⚠️ | 一期免 OCR 服务，二期加识别+人工复核环节 |
| 2 | AI 定位 | **核心依赖**：政策问答（RAG）+ 对话式发起报销 + 字段自动抽取 | LLM 为系统主干，必须有可替换供应商的适配层 |
| 3 | 报销制度 | 单一公司一套制度；字段数据化存储，为多主体配置化预留 ⚠️ | 一期规则校验硬编码 + 制度文档知识库，二期规则引擎 |
| 4 | 审批流程 | 首期仅"提交→管理员查看"，固定状态机；多级/会签二期 ⚠️ | 避免一期引入工作流引擎，状态字段已预留 |
| 5 | 系统对接 | 一期不对接 ERP/财务系统，支持导出 Excel 凭证 ⚠️ | 免集成层；导出用简单服务实现 |
| 6 | 打款方式 | 一期线下打款，系统止步于付款汇总表 ⚠️ | 免银企直连与对账模块 |
| 7 | 部署方案 | 私有化/内网优先；LLM 走云端 API（可换供应商）⚠️ | docker-compose 一键部署；数据不出内网的部分本地化 |
| 8 | 用户规模 | 百人级，月末潮汐并发可控 | 单体架构 + 单库，不上微服务 |
| 9 | 安全合规 | RBAC 两角色 + JWT；密码哈希；操作留痕；发票字段敏感存储 | 等保要求待确认 ⚠️，预留审计日志表 |
| 10 | 终端形态 | Web 端先行（员工对话页 + 管理端），小程序二期 ⚠️ | 前后端分离，API 设计不绑定终端 |

**一期验收口径**：员工登录 → 对话问制度（基于上传文档、标注出处）→ 对话式生成报销单草稿（缺字段自动追问）→ 管理员查看记录与制度维护。全链路可跑通即算一期成功。

## 二、技术架构

**四层架构**：入口层（Web + REST/SSE，JWT）→ 服务层（FastAPI 异步：认证/会话/报销单/知识库/审计）→ 智能体编排层（意图路由 + RAG 检索 + 表单抽取 + Prompt 管理 + LLM 适配层）→ 数据模型层（PostgreSQL + pgvector 一库两用，文档原件文件存储，Redis 可选）。

**关键选型及理由**：

| 选型 | 决策 | 理由 |
|------|------|------|
| 后端 | FastAPI + Python 3.11+（异步） | SSE 流式对话、生态成熟 |
| 向量库 | PostgreSQL + pgvector | 制度文档量级小，省掉独立向量库运维 |
| LLM | 统一适配层，供应商配置切换 | DeepSeek/Qwen/OpenAI 可替换，抽象接口隔离 |
| 文档切分 | 按"第X条/条款"结构切分 | 定长盲切会破坏条款完整性，检索质量差异大 |
| 部署 | docker-compose（pgvector + app） | 私有化交付最简路径 |
| ORM/迁移 | SQLAlchemy + Alembic | 标配 |

**核心数据表（6 张）**：users（角色 RBAC）、chat_sessions（会话）、chat_messages（消息，meta 存意图/引用/token）、policy_documents（制度文档+版本）、policy_chunks（切片+embedding 向量索引）、expense_drafts（草稿，fields jsonb + missing_fields 驱动追问，session_id 可回溯来源对话）。

## 三、第一周里程碑

| 天 | 目标 |
|----|------|
| D1–D2 | FastAPI 骨架 + JWT 登录 + 两角色权限 + 建表迁移 |
| D2–D3 | 知识库链路：文档上传 → 解析 → 条款切分 → embedding 入库 |
| D3–D4 | 对话链路：意图路由 + RAG + 流式回答，消息落库 |
| D5 | 报销链路：字段抽取 → 草稿落库 → 缺字段追问 + 列表接口 |
| 周末 | 管理端最小页面（文档上传 + 记录列表） |

## 四、遗留决策点（需业务方拍板）

1. 等保等级与数据合规硬性要求（影响安全设计深度）
2. LLM 供应商偏好及预算（云端 API 计费 vs 内网模型）
3. 二期是否上 OCR 与审批流（影响二期排期）
