# src-1 交付物 · 问答助手归档说明

> 对应任务清单 **src-1：问答助手归档**。本项目的起点是「报销助手智能体系统」——一个基于 RAG 的制度问答助手；随后在同一工程框架上扩展为「工程变更与签证协同」MVP。本页归档问答助手的完整演进线索与代码位置。

> 🌐 **线上可验证**：<https://change-visa-collab.app.workbuddy.host/?sharecode=WW7S3LLLSD>（演示账号 `zhangsan / abc123456`）——「AI 协同助手」页面的制度问答（带引用出处）即问答助手能力的线上形态。

## 一、演进脉络

| 阶段 | 内容 | 位置 |
| --- | --- | --- |
| 1. 裸问答原型 | 单脚本 RAG（BM25 中文 bigram + FAISS 混合检索 + RRF 融合，LLM 未配置时自动降级纯 BM25） | [`prototype/rag_prototype.py`](../prototype/rag_prototype.py) |
| 2. 服务化 | SSE 流式聊天接口（status / sources / delta / done 事件） | [`app/api/chat.py`](../app/api/chat.py) |
| 3. 知识库管理 | 文档上传 → 自动切片 → 向量化 / BM25 索引，管理后台可视化 | [`app/api/knowledge.py`](../app/api/knowledge.py) |
| 4. 工具化 | 问答助手成为 Agent 的检索工具 `search_policy` / `get_expense_standard`，与业务工具并列 | [`app/agent/registry.py`](../app/agent/registry.py) |
| 5. 工程化 | Harness 编排（5 轮上限、决策日志落库）、HITL 人工闸门 | [`app/agent/harness.py`](../app/agent/harness.py) |

## 三、与 MVP 的关系

问答助手不是独立遗留模块，而是 MVP 的 **AI 助手视图**：制度问答（RAG 附引用出处）、变更状态查询、AI 起草签证（人工核定）共用同一检索与对话底座，见 [`02-MVP项目说明.md`](./02-MVP项目说明.md)。
