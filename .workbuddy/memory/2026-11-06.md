## 修复线上登录失败（第四次·根因确认）
- 真正根因：WorkBuddy 分享网关会改写/覆盖标准 Authorization 请求头 → 登录接口（无需鉴权）能成功拿到 JWT，但之后所有带 Bearer 的请求验签必失败 401「登录已过期」，用户表现为"根本登录不了"
- 判定证据：线上无 Authorization 头/垃圾 token/有效 token 三种情况均返回同一 401，且无头时后端本应返回「未登录」→ 401 由网关产生或头被污染
- 修复：后端 deps.py 优先读自定义头 X-Auth-Token（Bearer 作本地兼容回退）；前端 3 处请求（api()/chat/stream/knowledge上传）同时发送两头条
- 线上验证（首次全绿）：登录200 → me/dashboard/changes/chat/sessions 全部 200；页面版本 v2026.11.06-2
- 提交：github 已推送（X-Auth-Token 修复）
